E-News

A modern blog web application built using Django, designed for content creators and readers alike.

**Features**

    User-friendly blog creation and management.
    Responsive design for seamless access on all devices.
    Rich text editing powered by TinyMCE.
    Secure authentication and user management.

**Technologies Used**

    Backend: Django (Python)
    Frontend: JavaScript, HTML, CSS. Bootstrap
    Other: PowerShell scripts for setup/automation (if applicable)

**Installation**

  Clone the repository:
  
    git clone https://github.com/Abdelhakime6/E-News.git
    cd E-News

Set up a virtual environment and install dependencies:

    python -m venv venv
    source venv/bin/activate  
    # On Windows, use `venv\Scripts\activate`


Apply migrations and run the development server:

    python manage.py migrate
    python manage.py runserver

Access the app at http://127.0.0.1:8000/.
